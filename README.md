# 📊 Student Marks Data Analysis using Python

## 📌 Project Overview

This project analyzes student marks using Python, Pandas, and Matplotlib.

The project reads student marks from a CSV dataset, calculates average marks, identifies the topper, determines Pass/Fail status, and visualizes student performance using a bar chart.

## 🎯 Objectives

- Analyze student marks using Python
- Calculate average marks of each student
- Identify the topper
- Determine Pass/Fail status
- Visualize student performance using Matplotlib

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV
